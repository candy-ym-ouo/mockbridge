# MockBridge —— 接口契约模拟服务（API Contract Simulation Service）

> 本项目采用**文档先行、实现落地**方式开发。当前仓库已包含可运行的 Go 服务、SQLite 迁移、管理前端、后台任务、自动化测试、构建与打包脚本。

## 1. 项目定位

MockBridge 是一个面向研发与测试团队的**接口契约模拟服务（Contract Simulation Service）**。它根据预配置的"契约"（请求匹配规则 + 响应模板 + 场景状态）对真实 HTTP 请求进行匹配、响应生成、调用记录与故障注入，使前端联调、接口测试、异常演练可以在后端服务尚未就绪时先行开展。

它**不是简易 Mock**，而是一个具备完整工程形态的独立服务：

- **分层架构**：API 层 / 服务层 / 仓储层 / 模型层 / 基础设施层；
- **数据库迁移**：内置版本化 SQL 迁移（`golang-migrate` 风格，支持向上迁移）；
- **后台任务**：场景定时切换调度器、调用记录过期清理、统计聚合；
- **测试**：单元测试 + 集成测试（HTTP 级），含覆盖率门槛；
- **完整构建验证**：`make build`、`make test`、`make vet`、`make lint`、`make verify` 一键全量校验。

## 2. 核心能力一览

| 能力 | 说明 | 对应文档 |
| --- | --- | --- |
| 配置请求匹配 | 方法、路径、请求头、查询参数、JSON Body 的任意组合匹配，支持通配与 JSONPath 取值 | 05-核心业务逻辑设计 |
| 动态响应 | 响应模板 + 变量注入（请求上下文、内置随机函数、数据库/场景状态），支持响应头与状态码自定义 | 05-核心业务逻辑设计 |
| 场景切换 | 同一契约可挂多个场景，场景可手动切换、按调用次数自动切换、按时间定时切换 | 05 / 07 |
| 调用记录 | 全量记录请求/响应/匹配结果/耗时，支持查询、统计、清理 | 05 / 07 |
| 延迟故障 | 延迟注入、错误注入、按概率故障、按调用序号故障 | 05 / 07 |
| 管理后台 | 简单前端界面：契约管理、场景控制台、调用记录、概览仪表盘 | 06-前端界面设计 |

## 3. 技术选型

| 类别 | 选择 | 理由 |
| --- | --- | --- |
| 语言 | Go 1.22+（标准库 `net/http` 路由） | 无第三方 Web 框架依赖，行数可控 |
| 数据库 | SQLite（`modernc.org/sqlite` 纯 Go 驱动） | 单文件部署，零外部依赖 |
| 迁移 | 内嵌 SQL 迁移 + 自研迁移执行器 | 满足"数据库迁移"硬性要求且不引入重依赖 |
| 配置 | 环境变量 + YAML 配置文件 | 简单、可运维 |
| 前端 | 服务端静态托管 + 原生 HTML/CSS/JS（无构建链） | 符合"简单前端界面"要求 |
| 测试 | 标准库 `testing` + `httptest` | 与项目规模匹配 |

## 5. 规模约束（硬性验收指标）

> 见 [docs/09-代码规模约束与文件规划.md](docs/09-代码规模约束与文件规划.md)

- Go 代码（**不含测试**）总行数：`2000 < L < 2200`，目标 2150 ± 30；
- Go 代码文件数：`20 < F < 25`，即 **21 ~ 24 个**，实际 23 个；
- 该约束由 `scripts/linecount.sh` 计量并在 `make verify` 中强制校验，超出即构建失败。

## 7. 快速开始

```bash
make verify         # 格式、vet、race 测试、覆盖率、构建、规模和冒烟验证
make run            # 使用 config.yaml 启动
make package        # 生成 bin/mockbridge-<os>-<arch>.tar.gz

# 管理前端: http://localhost:8080/admin/
# 模拟 API: http://localhost:8080/api/mock/**
# 管理 API: http://localhost:8080/admin/api/**
```
